# Nikon Z6 长曝光与肩屏倒计时v1

[English（旧版说明，暂未更新）](README.en.md)

适用机型仅为 Nikon Z6，基于 C3.80。

本版包含自定义快门声，将肩屏倒计时主体迁入卡载 SLOWCORE.BIN。

*特别注意*：声音菜单的触摸操作尚未修好；机械快门下，快门倒计时不可用。

## 包内文件

Custom shutter sound自定义快门声/

- cn/EG162080.BIN：本次中文版固件底座。
- cn/SLOWCORE.BIN：与本次中文版底座配套的长曝光及倒计时核心。
- cn/SHCORE.BIN：本次中文版声音核心，与 resident_dual_countdown_touch_v2_test 相同。
- en/：保留原有英文版 EG162080.BIN 与 SHCORE.BIN，本次不更新。
- [声音要求.md](<Custom shutter sound自定义快门声/声音要求.md>)：本次中文版的声音格式、编号与制作规范。
- [SOUND_SPEC.en.md](<Custom shutter sound自定义快门声/SOUND_SPEC.en.md>)：保留原有英文声音规范，适用于旧版英文固件。
- SHUTTER/1.WAV～4.WAV：沿用现有发布包的四个声音示例，依次为猫声、胶片相机快门声、鸟声和镜间快门声。
- SHUTTER.WAV：保留供旧版英文固件使用，本次中文版不读取。

仓库根目录的 README.md 为本次中文版说明；README.en.md 保留原有英文版说明，暂未更新。

本次中文版支持 SHUTTER/1.WAV～15.WAV，包内只提供 1～4 号示例，其余编号按需添加。卡根 SHUTTER.WAV 不再作为本次中文版的音源读取。已有的编号声音文件和相机生成的 SHUTTER.SEL 可沿用；不手动修改配置文件。

## 安装与使用

1. 备份卡上文件，并保存当前使用的固件底座及配套核心，便于回退。
2. 将 cn/ 内本次配套的 EG162080.BIN、SLOWCORE.BIN 和 SHCORE.BIN 三个文件复制到卡根目录。首次使用声音示例时，将包内整个 SHUTTER 文件夹也复制到卡根；如已有自己的编号声音，先备份，再按需复制，避免覆盖同名文件。已有的 SHUTTER.SEL 保留。即使此前使用过倒计时版，也必须同时更换本次的 EG162080.BIN 与 SLOWCORE.BIN。en/ 为保留的旧版英文固件，请勿与本次 cn/ 核心混用。
3. 相机中从“固件版本”执行更新，更新期间不要断电。按 Nikon 固件更新要求使用充足电量。更新完成后关机重开。
4. 进入 Setup → Slow shutter → On 开启功能。慢门开关不跨关机保存，重开机后需再次开启。
5. *特别注意*：声音菜单的触摸操作尚未修好；机械快门下，快门倒计时不可用。

## 使用说明

倒计时功能针对 1 秒及以上的有限曝光，在肩屏原快门位置显示。剩余时间大于或等于 10 秒时显示整数，小于 10 秒时显示一位小数；曝光结束或取消后恢复选定快门。*机械快门下不可用*，Bulb/Time 保持原显示。

使用时可分别检查 1 秒、30 秒和 60 秒曝光的倒计时，以及 10 → 9.9 秒的切换；机械快门下不适用。再检查曝光结束、取消后的快门显示恢复和照片保存，以及声音试听、拍摄出声、慢门关闭后再开启和关机重开后的功能状态。声音菜单的触摸操作仍为已知未修复问题。

更换声音时，按[声音要求.md](<Custom shutter sound自定义快门声/声音要求.md>)制作并替换对应编号的 WAV，选择该编号或使用“重新载入”，等读写完成后试听；仅更换声音文件无需重新刷固件。连拍时每张从头播放并截断上一声。

## 停用与恢复

缺失或不兼容的慢门核心不会启用长秒档和倒计时；声音核心仍独立加载。

本版底座与 SLOWCORE.BIN 必须配套使用，旧核心不能配新底座，新核心也不能配旧底座。若回到此前版本，请使用此前配套的 EG162080.BIN 执行更新，并换回对应的 SLOWCORE.BIN。
