# Wonder Lantern · Nikon Z6 三功能发布版 v1

[English](README.en.md)

2026-10-30。适用于 **Nikon Z6（一代），基于 C3.80**。本版包含自定义快门声、延长慢门与计时、自定义辅助线与可恢复 NEF 裁切。


## 文件与安装

```text
EG162080.BIN                 共用主固件，中英文只有这一份
cn/                         中文核心，三份文件复制到卡根目录
  Shuttersound.bin
  Slowshutter.bin
  Grid.BIN
en/                         英文核心，文件名同上
SHUTTER/1.WAV～4.WAV         沿用此前的四个示例音源
```

1. 关机，备份卡上自己的声音、记忆文件，以及当前主固件和配套核心。
2. 将 `EG162080.BIN` 和所选 `cn/` 或 `en/` 内的三份核心复制到卡根目录。**复制目录内的文件，不是把 cn/en 文件夹放到卡上。** 本次主固件和 Grid 核心均有更新，须配套使用。
3. 首次使用声音示例时，将 `SHUTTER/` 也复制到卡根目录。已有自定义声音的用户按需复制，避免覆盖同名音源。
4. 电量充足时从相机“固件版本”执行更新，等待完成后关机重开，更新中不要断电。开机等待挂载和卡读写结束，即可在设置菜单使用三个功能。

同一主固件下切换中英文，只需关机替换三个配套核心，随后开机。自定义菜单的语言由核心决定，不自动跟随原厂语言。若缺少某个核心，不增加该功能菜单；其余核心仍独立加载。旧版 SHCORE/SLOWCORE 或独立功能版核心不能通过改名混用。

## 三个功能

- **快门声音**：15 个编号槽，支持开启／关闭、选择、重新载入及播放。每张拍摄从头播放，连拍截断上一声。声音选择列表和“播放”使用方向键／OK；其余主菜单行保留触摸。更换 WAV 无需刷固件，选择编号或重新载入后试听即可。
- **延长慢门与计时**：在设置菜单开启或关闭；保留现有延长曝光和肩屏倒计时实现，曝光完成或取消后恢复快门显示。开关状态随卡记忆。
- **自定义辅助线**：二级菜单直接开启／关闭，并有“选择”和“裁切并遮挡”入口。1 为三等分；2～5 分别为 21:9、65:25、4:3、2.35:1；6～10 为空槽。保留机内辅助线开关联动。开启裁切并遮挡后，受支持 LCD 取景中的框外区域遮黑，NEF 写入可恢复裁切信息；Lightroom 修改照片中可重新调整或恢复完整画面。仅 JPEG 不写此类信息；JPEG+NEF 中只对 NEF 写入。

## 保留记忆与声音

相机会在卡根目录生成以下文件，本包不附默认记录，不要用别人的记录覆盖自己的设置：

| 文件 | 保存内容 |
|---|---|
| ShuttersoundMEM.SEL（8B） | 声音编号与开关 |
| SlowshutterMEM.sel（8B） | 慢门开关 |
| GridMEM.SEL（16B） | 辅助线开关、槽位、裁切并遮挡 |

从上一三功能包升级直接保留这三个文件。若从旧声音独立版升级，仅在新文件不存在时，将原 8B `ShutterMEM.SEL` 备份后改名为 `ShuttersoundMEM.SEL`；更早的 `SHUTTER.SEL` 同理，只改文件名，不编辑内容。不适用于将旧核心 BIN 改名。等待读写指示灯熄灭后再关机；记忆保存不承诺突然断电时的原子性。

声音使用 `SHUTTER/1.WAV`～`15.WAV`，无需填满。示例 1～4 依次为猫声、胶片相机快门声、鸟声和镜间快门声，沿用以前字节。详细格式见[声音要求](声音要求.md)。
