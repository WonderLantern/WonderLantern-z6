# 自定义快门声 · 声音规范

[English（旧版四槽声音规范）](SOUND_SPEC.en.md)

适用：本次 cn/ 中文版，Nikon Z6 C3.80，resident_dual_countdown_mount_v1_test。本版使用 1～15 号声音槽，不读取卡根 SHUTTER.WAV。

## 必须满足的格式

| 项目 | 要求 |
|---|---|
| 文件容器 | RIFF/WAVE、小端 |
| 编码 | 非压缩有符号 16 位整数 PCM，format tag=1 |
| 采样率 | 8000 Hz |
| 声道 | 单声道 |
| 字节率 / 块对齐 | 16000 bytes/s / 2 bytes |
| 文件头 | 标准 44 字节头，fmt 长度 16，data 紧随其后 |
| PCM 数据长度 | 非空、偶数，最多 17280 字节，即 8640 采样点 |
| 最大时长 | 1.08 秒，包括淡入、淡出与静音 |
| 最大文件大小 | 17324 字节 |

RIFF 和 data 声明长度须与实际文件一致，不能包含 LIST、JUNK、bext、封面等额外块。MP3、浮点 WAV、双声道和 44.1/48 kHz 文件须先转换，不能只改扩展名。固件不会自动截短超长文件；加载失败时保留上一种可用声音。

## 卡上命名

| 菜单编号 | 卡上路径 |
|---|---|
| 1 | /SHUTTER/1.WAV |
| 2 | /SHUTTER/2.WAV |
| 3 | /SHUTTER/3.WAV |
| 4 | /SHUTTER/4.WAV |
| 5～15 | /SHUTTER/5.WAV～15.WAV，按需添加 |

使用 1.WAV，不用 01.WAV；建议使用上述大写 ASCII 命名。菜单固定显示 1～15，不读取自定义名称，也不会因为添加 16.WAV 而增加菜单项。MEOW.WAV 等历史名称不作为本版编号槽读取。

本包只提供 1～4 号示例，不必填满所有槽。新增其他声音时使用 5.WAV～15.WAV。保留 1.WAV 作为无有效配置时默认尝试加载的声音；卡根 SHUTTER.WAV 不参与读取。无可用的 1.WAV 且没有已加载声音时，使用内置声音回退。

SHCORE.BIN 是必需的配套声音核心，放在卡根。SHUTTER.SEL 是相机生成的配置文件，保存编号与 On/Off，正常保存后重启恢复；不要手动修改。等读写指示灯熄灭后再关机。

## 声音制作建议

- 连拍优先：0.10～0.20 秒，辨识点尽量放在前 50 ms。
- 短提示：0.20～0.50 秒；完整音效：0.50～1.08 秒。
- 去掉前导静音，目标不超过 5 ms；头部淡入约 1～3 ms，尾部淡出约 5～10 ms。
- 建议峰值不超过 −0.5 dBFS，避免削顶。不同声音有效段 RMS 可从约 −8 dBFS 起调，以峰值及机身试听为准；这些是制作建议，固件不会自动归一化。

每张照片重新播放并截断上一声，不排队、不叠加。长音在连拍时只能听到开头属于预期行为，1.08 秒是格式硬上限。

## 定制流程

1. 保留原录音，另裁取成品并去掉前导静音。
2. 在音频编辑器转为单声道、8000 Hz、PCM16，处理首尾和响度。
3. 导出无附加元数据的标准 44 字节头 WAV，检查长度与大小。
4. 将文件命名为目标槽编号，复制到卡上的 SHUTTER 文件夹；覆盖同名文件前先备份。
5. 在相机上选择该编号或“重新载入”，等读写完成后用“播放”确认，再测试短曝光单拍及连拍。声音菜单的触摸操作尚未修好。
